Windows on KubeVirt

Golden image, VirtIO, Cloudbase-Init, Sysprep, and day-two operations. Full technical detail lives in the repository markdown.

Open full guide (WINDOWS_KUBEVIRT_PRODUCTION.md)

Operator workflow (summary)

  1. Install Windows from ISO; Ctrl+Shift+F3 → Audit Mode.
  2. Install VirtIO (storage + NetKVM) from virtio-win ISO.
  3. Install Cloudbase-Init; edit cloudbase-init.conf for KubeVirt config-drive paths and NoCloudConfigDriveService.
  4. Sysprep (Generalize + OOBE + Shutdown); publish disk to PVC / image.
  5. Deploy VirtualMachine with UEFI, virtio devices, and optional cloudInitConfigDrive userData.
