Veyron·How the stack worksKubernetes is the source of truth

One click in the console.
Straight to KVM.

Veyron is what you touch: a browser console, an HTTPS API and a CLI. It turns a template into a Kairon Machine.

Kairon schedules that Machine like Kubernetes schedules Pods, but a VM stays a VM: zero pods per VM, no libvirt in the hot path.

FluxVM runs on every host and speaks one REST API for four hypervisors. Pick one per Machine.

KVM does the rest. Nothing sits between the guest and the hardware except the hypervisor you chose.
