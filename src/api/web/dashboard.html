Monitoring
Observability stack discovery, VM policy hints, and threshold-based workload anomalies — all scoped by the namespace selector in the header.

    

  

    
VMRogue Performance Advisor

    

  

  

    
◎
Stack discovery
Detects Prometheus, Grafana, and Alertmanager Services across monitoring, prometheus, observability, and the active namespace.

    
⚡
Recommendations
Heuristic checks on KubeVirt VM specs: resource limits, virtio RNG, eviction strategy, and related best practices.

    
▲
Anomaly detection
Sustained CPU or memory above 85% (warning) / 95% (critical). Requires metrics-server and running virt-launcher pods.

    
⊢
Also in VMRogue
Per-VM live charts on the VM detail view, Alerts and Notifications pages, SLO / cost signals — use the nav to explore the full forge.
